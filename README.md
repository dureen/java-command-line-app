# Java Command Line App

> **Status: Archived** – Simple learning sample from 2023.

A minimal Java command-line application (Hello World).

## Requirements

- Java 11 or higher

## Project Structure

```
java-command-line-app/
└── sample-1/
    └── Main.java      # Basic Hello World
```

## How to Run

```bash
cd sample-1
javac Main.java
java Main
```

Expected output:

```
Hello World!
```
